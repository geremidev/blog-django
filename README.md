# Mon Blog Django

Un blog personnel développé avec Django, avec un design moderne et responsive.

## Fonctionnalités

- Articles avec catégories
- Filtre par catégorie
- Recherche par mot-clé
- Pagination
- Commentaires avec modération depuis l'admin
- Interface d'administration

## Technologies

- Python 3
- Django
- HTML / CSS (sans framework)
- SQLite
